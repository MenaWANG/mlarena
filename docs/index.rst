MLArena
========

Train, evaluate, explain, and tune scikit-learn compatible models through
a shared interface, with MLflow integration and utilities for data analysis.

Start with a complete binary classification example in :doc:`quickstart`,
then read :doc:`user-guide` for the behavior behind the defaults.
The :doc:`api` is generated from the package's current docstrings.
